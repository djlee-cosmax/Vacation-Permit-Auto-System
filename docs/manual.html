1. 소개서

작업자가 본인 휴대폰으로 휴가증을 직접 작성하면 클라우드에 자동 저장됩니다. 서무는 매일 한 번 사이트에서 일괄 취합 후 자동화 프로그램으로 그룹웨어에 등록합니다.

1.1 전체 흐름

  1. 작업자 휴대폰으로 사이트 접속 → 휴가증 작성
  2. 작성 즉시 클라우드 자동 저장
  3. 서무 매일 PC에서 사이트 접속 → [서버에서 불러오기] → [파일로 내보내기]
  4. [프로그램 실행] → 자동화가 그룹웨어에 임시저장
  5. 서무가 그룹웨어에서 검토·신청
  6. 잔여 휴가는 매일 저녁 서버가 자동 차감

1.2 역할별 권한 (사번 로그인 기반)

역할담당가능한 기능
관리자부서 담당자 1명모든 기능
서무부서 서무서버 불러오기 / 파일 내보내기 / 프로그램 실행
작업자각자 본인휴가증 작성 / 내 휴가증 조회·취소

※ 모바일은 어떤 사번이든 작업자 화면만 표시 (서무 작업은 PC 전용)

본인 정보만 열람됩니다. 작업자로 로그인하면 서버에서 본인 기록만 내려받습니다. 다른 사람의 이름·연락처·잔여 휴가는 화면에 표시되지 않으며, 명단 조회는 서무·관리자만 가능합니다.

2. 매뉴얼 (작업자용)

2.1 접속 & 로그인

주소: https://djlee-cosmax.github.io/Vacation-Permit-Auto-System/

  • 사번 + 비밀번호 1234 입력 → [로그인]
  • 아이디 저장 / 👁 보기 토글 지원
  • 자리를 비우면 자동 로그아웃됩니다 — 작업자 10분, 서무·관리자 8시간
비밀번호 변경 (필수): 첫 로그인 후 상단 [내 정보] → [비밀번호 변경] → 숫자 6~10자리. 초기 비밀번호(1234)로 로그인하면 변경 안내가 자동으로 뜹니다.
비밀번호를 잊었을 때: 서무에게 초기화를 요청하세요. 서무가 접수하면 이름 옆에 [초기화 대기] 표시가 붙고, 관리자가 처리하면 초기화됩니다. 요청 즉시 바뀌지는 않으니 표시가 사라진 뒤 사번 + 1234로 로그인해 새 비밀번호를 등록해 주세요.

2.2 홈 화면에 추가 (모바일 권장)

휴대폰 홈 화면에 앱 아이콘으로 추가하면 한 번 탭으로 실행됩니다.

  • iOS Safari — 하단 공유 버튼 → "홈 화면에 추가"
  • Android Chrome — 우상단 ⋮ → "홈 화면에 추가"
  • 홈 화면 앱에서 새로고침이 필요할 때는 상단 ↻ 아이콘 클릭

2.3 휴가증 작성

  1. 구분 선택 (연차 / 반차 / 반반차 / 생휴 / 하기휴가 / 결근 등)
  2. 개수 입력 (예: 연차 2개)
  3. 기간 시작일~종료일 선택
  4. 사유 입력
  5. [+ 추가] 클릭 → 클라우드 자동 저장

※ 한 사람이 여러 유형(예: 연차+반차)을 쓸 때는 휴가증을 따로 작성

※ 같은 날짜에 합계 1일 초과하거나 동일 휴가증이 있으면 등록 차단 — 기존 휴가증 삭제 후 재작성

잔여가 부족하면 작성이 차단됩니다. 신청 일수가 남은 휴가보다 많으면 잔여 ○일 / 신청 ○일 안내가 뜨고 등록되지 않습니다. 하기휴가는 개수로 비교합니다(1개 = 3일). 잔여가 맞지 않으면 서무에게 확인을 요청하세요.
하기휴가는 한 장으로 씁니다. 1개가 연속 3일이라, 구분에서 하기휴가를 고르면 종료일이 자동으로 3일 뒤로 채워지고 고칠 수 없습니다. 하루씩 나눠 세 번 쓰면 3개를 쓴 것으로 잡히므로 그렇게 하지 마세요.
처리 완료된 휴가증 중복 등록 차단: 본인이 작성하고 서무가 처리 완료한 휴가증과 동일한 내용(같은 시작일·종료일·종류·개수)은 다시 등록할 수 없습니다. 작성 전 [내 휴가증]에서 처리 상태를 확인하세요.

※ [+ 추가]는 한 번만 눌러 주세요 — 연속으로 눌러도 1건만 등록되도록 막아 두었습니다.

2.5 내 휴가증 조회

상단 [내 휴가증] 클릭 → 처리 완료된 본인 휴가증 바로 표시 (최근 14일)

모달 위쪽에 본인 잔여 휴가가 개수 단위로 함께 표시됩니다 — 연차 · 생휴(여성만, 당월 기준) · 하기휴가(5~10월만 사용, 시즌 외에는 회색 표시). 아래에는 올해 누적 사용량도 나옵니다.

※ 작성 전 여기서 남은 개수를 먼저 확인하세요. 잔여보다 많이 신청하면 작성 단계에서 막힙니다.

잘못 작성 시: 작성 직후 우측 카드의 [삭제]로 취소. 서무 처리 후엔 서무에게 별도 처리 요청.

3. 매뉴얼 (서무용)

3.1 로그인

주소: https://djlee-cosmax.github.io/Vacation-Permit-Auto-System/

  • 서무 사번 + 본인 비밀번호 입력 (초기 1234는 첫 로그인 때 변경)
  • 로그인 시 자동으로 서무 권한 부여 → 추가 버튼 표시
  • 모바일에서는 서무 권한 비활성 — PC에서만 사용
  • 서무·관리자는 자동 로그아웃까지 8시간 (작업자 10분과 다름)

3.2 매일 사용 절차

  1. PC에서 사이트 접속 → 서무 사번으로 로그인
  2. 우측 카드의 [서버에서 불러오기] 클릭 → 미처리 휴가증 가져오기 + 자동 처리 완료 마크
  3. 화면에서 휴가증 목록 검토
  4. 상단 [파일로 내보내기] → JSON + XLSX 다운로드
  5. [프로그램 실행] 클릭 → 자동화가 그룹웨어에 임시저장
  6. 완료 알림 확인 → 그룹웨어 검토 후 신청 처리

※ 화면의 버튼에 ① ② ③ 번호가 붙어 있습니다. 그 순서대로 누르면 됩니다.

[서버에서 불러오기] = 자동 처리 완료: 불러오는 즉시 서버에 처리 완료로 마크됩니다. 작업자가 이후 수정할 수 없으며, 다음 불러오기에 중복으로 나오지 않습니다.
잔여 휴가 차감은 서무가 따로 하지 않습니다. 매일 저녁 서버가 처리된 휴가증을 확인해 자동으로 차감합니다. 화면에서 차감이 됐든 안 됐든 결과는 같으니, 잔여를 손으로 맞추지 않으셔도 됩니다.
run.bat을 직접 여는 방식은 쓰지 마세요. 예전 안내였습니다. [프로그램 실행]을 눌러야 같은 자동화가 돌면서 화면 기록도 함께 맞춰집니다.

3.3 자동화 최초 설치 (한 번만)

  1. Python 3.10~3.12 설치 — python.org/downloads ("Add Python to PATH" 체크)
  2. 자동화 폴더(또는 ZIP) 적당한 위치에 배치 (예: D:\휴가증자동화\) — ZIP은 풀기 전 우클릭 → 속성 → "차단 해제"
  3. setup.bat 더블클릭 → 자동 설치 완료 대기
  4. 첫 run.bat 실행 → 그룹웨어 로그인 → 이후 자동 유지
    최초 로그인 때만 직접 실행합니다. 평소에는 화면의 [프로그램 실행]을 쓰세요.

3.5 작업자 비밀번호 초기화

작업자가 비밀번호를 잊었을 때 처리하는 절차입니다. 비밀번호는 복원할 수 없는 형태로 보관되므로 초기화만 가능합니다.

  1. PC에서 [작업자 명단] → 해당 작업자 행의 [초기화 요청] 버튼 클릭 → 요청 접수
    이 단계에서는 아직 초기화되지 않습니다. 이름 옆에 [초기화 대기] 표시가 붙습니다.
  2. 관리자가 GitHub Actions의 [계정 관리] 워크플로를 실행
    action = reset / 사번 = 해당 작업자 사번
    처리되면 [초기화 대기] 표시가 사라집니다.
  3. 작업자에게 사번 + 1234로 로그인하도록 안내
  4. 작업자가 로그인하면 새 비밀번호 등록 안내가 자동으로 표시됨
보안 질문은 더 이상 사용하지 않습니다. 답변만 알면 남의 비밀번호를 바꿀 수 있어 폐지했고, 비밀번호는 Firebase 인증 서버가 보관합니다. 그래서 브라우저에서는 본인 것만 변경할 수 있습니다.

3.6 퇴직자 명단 삭제

퇴직·전출로 명단에서 완전히 빼야 할 때의 절차입니다. 명단 화면에서 지우는 것만으로는 삭제되지 않습니다 — 새로고침하면 서버 명단에서 다시 채워집니다.

  1. 관리자가 GitHub Actions의 [계정 관리] 워크플로 실행
    action = remove / 사번 = 퇴직자 사번 / confirm = 비워둠
  2. 실행 로그에서 삭제 대상과 백업 JSON 확인 (이 단계에서는 아무것도 지우지 않음)
  3. 맞으면 같은 워크플로를 confirm = DELETE 로 다시 실행 → 실제 삭제
삭제되는 항목: 작업자 명단, 잔여 휴가 기록, 해당 작업자의 휴가증 기록, 로그인 계정.
각 기기의 명단은 다음 접속 시 자동으로 갱신되어 사라집니다.
